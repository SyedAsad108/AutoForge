AutoForge Smart Manufacturing Plant

Industry 4.0 Industrial Intelligence Platform -- Phases 1, 2 & 3

A cloud-native real-time telemetry streaming platform that simulates a realistic 24-machine automotive manufacturing plant. The system generates stateful, correlated, anomaly-capable industrial telemetry at 1 Hz per machine, and exposes a production-style FastAPI ingestion gateway for telemetry validation, enrichment, buffering, and persistence.

Validation Pipeline

Layer 1 -- Schema Validation (Pydantic v2)

  • Required fields, types, nested telemetry structure
  • Enum enforcement for machine_type, status, anomaly_type
  • Severity/degradation bounds (0.0--1.0)

Layer 2 -- Range Validation (ValidationEngine)

  • Per-machine-type telemetry field bounds
  • Examples: conveyor RPM 0--5000, CNC tool_wear 0--100%, temperature -10--250 C

Enrichment

Every accepted event receives server-side metadata:

  "metadata": {

    "backend_node": "ingestion-node-01",
    "ingestion_source": "api",
    "schema_version": "v1"
  }
}

Producer Abstraction

class ProducerInterface(abc.ABC):
    async def publish_event(event) -> bool
    async def publish_batch(events) -> int
    async def health_check() -> bool

LocalProducer -- writes to date-partitioned NDJSON files under data/ingestion/. Future KinesisProducer will implement the same interface.

Observability

  • Structured logging (console + rotating file)
  • Request ID middleware (UUID per request)
  • Request timing middleware (latency tracking)
  • Metrics endpoint: throughput, latency, queue depth, anomaly count, validation failures

Setup Instructions

Prerequisites

  • Python 3.11+

Install

cd autoforge

# Simulator dependencies
pip install -r requirements.txt

# Backend dependencies
pip install -r backend/requirements.txt

Configure

cp .env.example .env
# Edit .env to customise intervals, API key, etc.

Running

Start the Ingestion API

uvicorn backend.main:app --reload

The API starts on http://localhost:8000 with interactive Swagger docs at /docs.

Start the Factory Simulator

python simulator/main.py

Emits telemetry to stdout and persists NDJSON to data/raw_stream/.

Run All Tests

# Phase 1+2 tests
python -m pytest tests/ -v

# Phase 3 backend tests
python -m pytest backend/tests/ -v

Security

  • API Key: All telemetry endpoints require X-API-Key header
  • CORS: Configurable origins via CORS_ORIGINS env var
  • Request IDs: Every request gets a UUID for traceability
  • Default dev key: autoforge-dev-key-2026 (change in production)

Performance

  • Async throughout: FastAPI + asyncio event loop, no blocking I/O
  • Bounded buffer: Configurable 10K-event queue with overflow eviction
  • Batched persistence: Drain loop processes up to 100 events per cycle
  • Low latency: ~0.07ms avg ingestion latency per event locally
  • Target: 500+ events/sec on standard hardware
